# Weather Dash Board — Hosting Instructions

This repository contains a simple static site. To host it on GitHub Pages:

1. Create a new repository on GitHub (choose any name).
2. On your machine, run the commands below, replacing the remote URL.
3. After pushing, GitHub Actions will build and deploy the site to GitHub Pages.

Commands to run locally:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

Visit `https://USERNAME.github.io/REPO/` after deployment.
